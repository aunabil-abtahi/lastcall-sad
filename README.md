# LastCall

LastCall is a university software project for listing surplus food and reselling event tickets. The original DBMS application lets buyers reserve food or tickets and records changes in ticket ownership after a sale.

The proposed System Analysis and Design (SAD) project would extend event-ticket resale to a broader marketplace for unused tickets, coupons, and vouchers. Bus, train, and event tickets would be eligible only where transfer is lawful and the issuer permits it. The same conditions would apply to coupons and vouchers.

The [original LastCall application](https://github.com/aunabil-abtahi/lastcall) uses PHP, MySQL, HTML, CSS, and JavaScript.
